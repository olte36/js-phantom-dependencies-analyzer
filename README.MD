# JavaScript phantom dependencies analyzer

This project is for analyzing JS packages for [phantom dependencies](https://rushjs.io/pages/advanced/phantom_deps). It is nice to have a consistent dependency tree that might be achieved by using [pnpm](https://pnpm.io/) for example. Knowing phantom dependencies of a JS package allows to [fix them](https://pnpm.io/package_json#pnpmpackageextensions).

## Status
The project is not ready, work is in progress.
